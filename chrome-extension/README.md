# ChatGPT 批量生图下载 Chrome 扩展

该扩展在 ChatGPT 网页端为你批量发送提示词，并在图像生成完成后按顺序自动下载图片。

## 功能

- 在弹窗中批量输入提示词（每行一个），自动依次发送到 ChatGPT 图生对话。
- 自动监听生成结果，下载图片并以递增序号命名（默认 `chatgpt-images/001.png` 开始）。
- 可自定义保存目录前缀与起始序号，方便延续批次。
- 随时停止任务，并在弹窗查看剩余任务与下载计数。

## 使用步骤

1. 打包加载  
   - 打开 Chrome → `chrome://extensions` → 开启「开发者模式」。  
   - 点击「加载已解压的扩展程序」，选择本仓库中的 `chrome-extension` 目录。
2. 打开 `https://chat.openai.com/` 或 `https://chatgpt.com/`，进入你已选定图像模型的对话。
3. 点击扩展图标，粘贴多条提示词（每行一条），设置保存目录前缀与起始序号，点击「开始生成」。
4. 扩展会逐条发送提示词、等待生成并下载图片；下载文件会按顺序保存在浏览器默认的下载目录下对应的子文件夹内。

> 提示：请确保已经在 ChatGPT 页面切换到可生图的模型，扩展只负责发送提示词与抓取生成的图片链接。
